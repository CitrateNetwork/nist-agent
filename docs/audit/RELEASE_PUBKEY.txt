How operators consume it
------------------------

The installer (`citrate-agent install <bundle>`) verifies the
release manifest's detached signature against this public key:

    citrate-agent install /path/to/extracted-bundle \
        --release-pubkey-hex ac6ac3e45e88befb7e1b600a68baa7b75a1289bba4bec092807fcebafd090fd7

Or via env:

    NIST_AGENT_RELEASE_PUBKEY_HEX=ac6ac3e45e88befb7e1b600a68baa7b75a1289bba4bec092807fcebafd090fd7 \
    citrate-agent install /path/to/extracted-bundle

Trust-root policy
-----------------

This soft key signs every release tagged BEFORE the HSM ceremony
described in HSM_SEAM.md. Releases under this key are flagged
`prerelease: true` in the GitHub release UI and marked
"pre-release / not for production" in the release notes.

When the HSM ceremony completes, a NEW public key is issued and
recorded in CitrateNetwork/.github/SECURITY.md as the
production trust root. This soft key is then **revoked**: a
revocation record is added to this file documenting the
soft → HSM transition date.

Until that transition, operators who want to exercise the
release path on the air-gap test runbook
(`docs/audit/AIRGAP_TEST.md`) use the soft-key public above.
